# 课后小助手 0.5.1

本仓库仅保存签名程序更新和更新信息，不含课堂录音、源代码或私钥。

整理“今天学了什么、重点单词、短语与句型、本课复习”，不评价孩子表现。优先课题、开头介绍与结尾复习；可选填写课题和复习页文字。软件只录音，不读取课件画面。

0.5.1 改善只返回课题而遗漏词句的问题，过滤课堂管理话语，保留可编辑原文供核对。

已安装 0.4 或 0.5 且完成模型准备：在应用里点击“检查更新”。首次安装请使用完整离线包，下面的小更新不含模型。

[0.5.1 程序更新包](downloads/QkidsHelper-0.5.1-arm64.zip)

升级后可用“处理已保存的录音”重新处理旧课堂，无需重录。适用于 Apple 芯片 Mac、macOS 15 及以上。
