# 课后小助手 0.6.0

本仓库仅保存签名程序更新和更新信息，不含课堂录音、私人样例、源代码或私钥。

0.6.0 更新：
- 课后反馈改为连续段落，包含本课词汇、句型和具体复习建议，不推断孩子表现。
- 新课堂文件夹命名为 MM-dd_孩子代号，例如 11-22_小禾；同名加序号，不覆盖原有录音。完整日期仍保存在课堂元数据里。
- 重新处理旧录音时恢复原课堂的孩子代号，仍可复用转写。

已安装 0.4 或 0.5 且完成模型准备：在应用里点击“检查更新”。首次安装请使用完整离线包，下面的小更新不含模型。

[0.6.0 程序更新包](downloads/QkidsHelper-0.6.0-arm64.zip)

软件只录音，不读取课件画面；课题和复习页文字可选填写。适用于 Apple 芯片 Mac、macOS 15 及以上。
